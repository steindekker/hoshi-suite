# Hoshi suite

Hoshi Reader, chimahon and the shared `hoshi-card` library in one place, plus the tools that build the first-run setup catalog.

- `hoshi-reader/`: Hoshi Reader for Android (submodule)
- `chimahon/`: chimahon (submodule)
- `hoshi-card/`: shared card layer used by both apps (submodule)
- `server/`: pack builder, setup file server and publish script

Clone with `git clone --recurse-submodules`. See `AGENTS.md` for how the pieces fit together.
